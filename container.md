# Suite 2P Inscopix Container

An Inscopix container which has the [suite2P open-source toolbox](https://github.com/MouseLand/suite2p)

**Base Image:** [ubuntu:20.04](https://gallery.ecr.aws/lts/ubuntu)

**Python Version:** Python 3.9

## Packages Installed:
The following python packages are installed:

* pynwb==2.8.1
* hdmf==3.14.0
* dandi==0.63.0
* numpy==1.26.4
* scikit-learn==1.4.2
* scipy==1.13.0
* suite2p==v0.0.3
* imageio==2.19.0
* imageio-ffmpeg==0.4.7
* isx==2.0.0
